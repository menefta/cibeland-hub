# CIBELAND Hub

Repositorio interno de documentación para CIBELAND, creado con Docusaurus.

## Uso sin instalar nada: GitHub Codespaces

1. Abre **Code → Codespaces → Create codespace on main**.
2. En la terminal del Codespace ejecuta:

```bash
npm install
npm start -- --host 0.0.0.0
```

GitHub abrirá una vista previa de la web.

## Uso local

Requiere Node.js 20 o superior.

```bash
npm install
npm start
```

## Publicación

El proyecto incluye `.github/workflows/deploy.yml` para GitHub Pages. En el repositorio, entra en **Settings → Pages** y selecciona **GitHub Actions** como origen.

La URL prevista es:

`https://menefta.github.io/cibeland-hub/`
