# Procedimiento: atención al cliente

## Principios
- Responder con educación y claridad.
- No prometer fechas que no estén confirmadas.
- Registrar incidencias repetidas para corregir su causa.
- Proteger los datos personales del cliente.

## Incidencias mínimas a registrar
Fecha, pedido, producto, problema, solución, coste y estado final.
