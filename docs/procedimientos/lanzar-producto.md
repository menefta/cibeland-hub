# Procedimiento: lanzar un producto

## Responsable
Asignar una persona responsable antes de comenzar.

## Pasos
- [ ] Definir cliente, necesidad y propuesta diferencial.
- [ ] Crear ficha de producto.
- [ ] Seleccionar materiales y proveedores.
- [ ] Fabricar prototipo.
- [ ] Probar seguridad, resistencia, talla y acabado.
- [ ] Calcular coste, PVP y margen.
- [ ] Preparar fotografías, vídeo y texto comercial.
- [ ] Revisar requisitos legales, etiquetado y advertencias.
- [ ] Publicar lote piloto.
- [ ] Recoger incidencias y opiniones.
- [ ] Aprobar producción regular o corregir.
