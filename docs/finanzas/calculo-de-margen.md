# Cálculo de margen

## Fórmulas

```text
Coste total = materiales + mano de obra + packaging + comisiones + coste medio de incidencias
Beneficio bruto = PVP sin IVA - coste total
Margen bruto % = beneficio bruto / PVP sin IVA × 100
```

## Plantilla
| Concepto | Importe |
|---|---:|
| PVP con IVA | 0,00 € |
| PVP sin IVA | 0,00 € |
| Coste total | 0,00 € |
| Beneficio bruto | 0,00 € |
| Margen bruto | 0 % |
