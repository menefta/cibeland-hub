# Bienvenida a CIBELAND Hub

Este repositorio centraliza la información operativa, creativa y comercial de **CIBELAND**.

## Cómo usarlo

1. Busca la sección correspondiente en el menú lateral.
2. Edita los archivos Markdown desde GitHub o en tu ordenador.
3. Crea una rama para cambios importantes y solicita revisión mediante un *pull request*.
4. No guardes contraseñas, datos bancarios ni información sensible de clientes.

## Normas básicas

- Una ficha por producto.
- Los precios deben indicar fecha y moneda.
- Las decisiones importantes se documentan.
- Las imágenes grandes se enlazan desde Drive o un gestor de recursos; no se duplican sin necesidad.
- Cada procedimiento debe tener responsable y fecha de revisión.
