# Mapa de fabricación

## Capacidades previstas
- Impresión 3D de filamento: prototipos, soportes, plantillas y piezas funcionales.
- Impresión de resina: piezas detalladas y maestros para moldes.
- Moldes de silicona: jabones y objetos personalizados.
- Láser: placas, etiquetas, packaging y accesorios compatibles.
- Bordado: parches, nombres y diseños textiles.

## Flujo general
Diseño → prueba de material → prototipo → validación → cálculo de coste → lote piloto → control de calidad → publicación.
