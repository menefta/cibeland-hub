# Manual de marca

## Personalidad
CIBELAND es una marca de mascotas divertida, reconocible, descarada y cariñosa. Puede ser bizarra, pero nunca cruel con animales ni clientes.

## Voz
- Directa y cercana.
- Humor visual y frases memorables.
- Evitar lenguaje frío o excesivamente corporativo.
